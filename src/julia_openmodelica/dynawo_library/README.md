# Pinned Dynawo Modelica library

A copy of the Modelica library that Dynawo distributes under `ddb/Dynawo/`, taken from a
nightly build, with the `Examples/` package left out.

Version: 1.8.0 (rev:master-62d451a)

The notebooks in this folder read their Dynawo models from here, so they do not depend on
which Dynawo version happens to be installed on the machine. Dynawo itself is not needed
to run them.
